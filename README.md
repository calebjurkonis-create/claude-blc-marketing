# The Complete Claude Marketing Course for Non-Techies

A follow-along pack for running your marketing from Claude Cowork. Every prompt from the video, with a short explainer and a diagram for each step.

## What's inside
1. Make Content in Your Voice: set up your workspace, build voice skills (email, blog, newsletter, LinkedIn) and a content-repurposing skill
2. Generate Images and Video with Higgsfield (includes a downloadable skills plugin)
3. Find Customers and Reach Out
4. Track What Is Working (with Supabase)
5. Get Found in Search and AI

Plus a bonus section at the end.

## How to use it
Open index.html in any browser. Work top to bottom and use the Copy buttons to paste each prompt into Claude.
