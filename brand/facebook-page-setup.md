# Caleb & Moose Facebook page: add the RSVP website

Website: `https://otter-k66vr8.my.canva.site/`

Steps are for the Facebook phone app. Facebook moves these buttons around, so if a name doesn't match exactly, look for the closest one.

## 1. Put the website in the page info (2 minutes)
1. Open Facebook → tap your profile picture (top or bottom right) → switch to the **Caleb & Moose** page.
2. On the page, tap **⋯** (or **Edit**) → **Edit details** (sometimes **Page settings → Page setup → Contact info**).
3. Find **Website** → tap **Add website** → paste `https://otter-k66vr8.my.canva.site/` → **Save**.
4. While you're there, check that **Phone** = 407-735-6371 and **Category** = Insurance Agent.

## 2. Make the big button on the page open the website
1. On the page, tap the action button under the cover photo (it may say **Add button**, **Message** or **Edit button**).
2. Choose **Sign up** → paste the website link → **Save**.

## 3. Pin a post so visitors see the workshop first
1. Make a post from the page using the "Lunch is on us" image, with the Ad 2 web text from `seminars/grove-house/meta-ads.md`, and paste the website link at the end.
2. On the post, tap **⋯** → **Pin to top of page** (or **Feature**).

## 4. Test it
Open the page from a friend's phone (or log out), tap the button and the link, and make sure the site opens.
